### 12. Full-Stack Partnership & Inquiry System
- **Public Form**: High-contrast, clean paper expression of interest form in the Contact section and the Navbar modal.
- **REST API (`POST /api/inquiries`)**:
  - Validates and sanitizes inputs (Name, Email, Organization, Phone, Category, Message).
  - Generates a unique traceable Inquiry ID (e.g., `DIK-20261110-XXXX`).
  - Persists all submissions to `data/inquiries.json`.
  - Dispatches an **Internal Admin Notification** to private recipient list (`dikaiosunepvtltd@gmail.com` and `admin@dikaiosune.in`) with `replyTo` set directly to the partner's email.
  - Dispatches a formal **Partner Acknowledgement Email** to the partner's submitted email address with inquiry details and expected follow-up timelines.
  - **Privacy Enforcement**: The internal recipient emails are kept strictly server-side in `.env` and are **never** bundled or exposed in public client JavaScript or HTML.
  - **Outbox Auditing**: Renders full email artifacts into `data/outbox/` for instant offline inspection and audit trails.
  - Supports live SMTP delivery (Gmail, Google Workspace, AWS SES, SendGrid, etc.) via `.env`.

## 🚀 Running the Project

### Full-Stack Server (Backend API + Production Frontend)
```bash
npm start
# or
node server.js
```
Runs the Express full-stack application on port 3000 (`http://localhost:3000`), serving both the optimized frontend and the `/api/inquiries` backend endpoints.

### Development Client
```bash
npm run dev
```
Runs the Vite development server with Hot Module Replacement (HMR) at `http://localhost:5173`.

### Production Build
```bash
npm run build
```
Compiles and bundles the frontend application into `dist/`.

## ⚙️ Environment Configuration (`.env`)

Configure the backend via `.env` (refer to `.env.example`):
```env
PORT=3000

# Private Internal Admin Recipients (Server-side only, never sent to browser)
ADMIN_EMAILS=dikaiosunepvtltd@gmail.com,admin@dikaiosune.in
FROM_EMAIL="Dikaiosune Mega Project" <admin@dikaiosune.in>

# SMTP Configuration (Optional: live email dispatch)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your_email@gmail.com
SMTP_PASS=your_app_password
```
